# KwikGrade – AI Graded Quiz App

KwikGrade is an AI-powered quiz platform for teachers and students. Teachers can create and manage quizzes, while students can take quizzes and receive instant AI-generated feedback.

## Features

- **Teacher Dashboard:** Create classes, add quizzes, and view student attempts.
- **Student Dashboard:** Join classes, take quizzes, and view results.
- **AI Grading:** Instant feedback and scoring powered by AI.
- **Secure Login:** Separate roles for teachers and students.

## Getting Started

### 1. Installation

- Visit the app at _____.
- Or, if you have Flutter installed, you can run:
  ```sh
  flutter run
  ```

### 2. Creating an Account

- Launch the app.
- Click **Sign Up**.
- Fill in your full name, username, password, and select your role (Student or Teacher).
- Click **Sign Up** to create your account.

### 3. Logging In

- Enter your username and password on the login screen.
- Click **Log In**.

### 4. For Teachers

- After logging in as a teacher, create a class and share the class code with your students.
- Create quizzes for your class, specifying questions and expected answers.
- View student attempts and override AI scores if needed.

### 5. For Students

- After logging in as a student, join a class using the class code provided by your teacher.
- Select available quizzes, answer questions, and submit.
- Instantly view your AI-generated score and feedback.

## Troubleshooting

- If you forget your password, please contact your teacher or administrator.
- For technical issues, ensure you have a stable internet connection.
